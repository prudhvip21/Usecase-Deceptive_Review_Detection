# Deceptive Review Detection

Detect fake hotel reviews that were deliberately written to sound authentic.

## Approach

- Linguistic feature engineering with spaCy
- TF-IDF, pretrained word embeddings and sentence embeddings
- Classification with Logistic Regression, Naive Bayes, KNN and XGBoost

## Results

Accuracy of up to about 0.87 to 0.90 across the models in the saved notebook output.
